# Portfolio — Nadtapong Saesung

เว็บพอร์ตโฟลิโอส่วนตัว นักศึกษาวิทยาการคอมพิวเตอร์ ปี 4 RMUTK
กำลังหาที่ฝึกงานตำแหน่งโปรแกรมเมอร์ 16 พ.ย. 2026 – 12 มี.ค. 2027

**เปิดดู:** ดับเบิลคลิก `index.html` ได้เลย ไม่ต้องติดตั้งหรือ build อะไร

## โครงสร้าง

```
index.html          ทั้งเว็บอยู่ในไฟล์นี้ไฟล์เดียว (HTML + CSS + JS)
assets/
├─ certs/           ใบประกาศนียบัตร
├─ shots/           ภาพหน้าจอและกราฟจากโปรเจกต์
└─ *.pdf, *.png     เรซูเม่และรูปถ่าย
```

## จุดที่ตั้งใจทำ

- **6 หน้าในไฟล์เดียว** ใช้ hash routing (`#projects`) กดเปลี่ยนหน้าทันที ไม่ต้องเลื่อนยาว
- **กราฟผลตอบแทนรายปีวาดด้วย SVG เอง** ไม่พึ่งไลบรารี และปรับขนาดตัวอักษรตามความกว้างจอ
  เพราะบนมือถือ SVG ถูกย่อจนตัวหนังสืออ่านไม่ออก
- **แกลเลอรีใบประกาศ** กดดูรูปเต็ม เลื่อนด้วยลูกศร ปิดด้วย Esc
- **สั่งพิมพ์ได้จริง** มี stylesheet แยกที่กางส่วนที่พับไว้และสลับเป็นโทนสว่าง
- ทดสอบแล้วไม่ล้นขอบจอที่ความกว้าง 320px และ 375px

## แก้เนื้อหา

ตัวแปรที่ต้องแก้บ่อยรวมไว้ท้ายไฟล์ `index.html` ที่เดียว —
`GOLD_SHOTS`, `SHOTS`, `CERTS`, `CONTACTS`
เพิ่มใบประกาศใหม่ = วางรูปใน `assets/certs/` แล้วเติม 1 บรรทัดใน `CERTS`
