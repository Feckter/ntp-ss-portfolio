บั๊กที่พบบ่อยที่สุดในงานทำนายราคา คือเผลอเอาข้อมูลอนาคตมาสอน แล้วได้ผลสวยเกินจริง เพราะทำนายล่วงหน้าไป 12 ช่วง แถวสุดท้ายที่เฉลยแล้วจึงอยู่ห่างออกไป 12 แถว ไม่ใช่แถวติดกัน

# goldai/model.py — ตัดข้อมูลสอนที่ t-horizon ไม่ใช่ t-1
def walk_forward(X, y, horizon, train_window, refit_every):
    preds = {}
    for t in range(train_window + horizon, len(X)):
        # แถวล่าสุดที่ "รู้คำตอบแล้ว" คือ t - horizon
        # ถ้าใช้ t-1 = แอบดูอนาคต ผลจะสวยเกินจริงทันที
        end   = t - horizon
        start = end - train_window
        if t % refit_every == 0:
            model = LinearRegression().fit(X[start:end], y[start:end])
        preds[t] = model.predict(X[t:t+1])[0]
    return preds
ดูโครงสร้างระบบ — ทำไม Python เป็นสมอง และตัวส่งคำสั่งเป็นมือ

  • แยกข้อความออกเป็นช่อง ๆ — สลิปแต่ละธนาคารหน้าตาไม่เหมือนกัน ผมเขียนตัวแยกข้อความแยกไว้อีกไฟล์ เพื่อดึงยอดเงิน วันเวลา และเลขอ้างอิงออกมา แล้วเติมลงฟอร์มให้ แต่ยังไม่บันทึก
  • ให้คนเป็นคนตัดสินใจเสมอ — เพราะการอ่านรูปแม่นราว 80–90% สลิปที่ถ่ายเอียง เบลอ หรือมีแสงสะท้อนก็อ่านผิดได้ ระบบจึงบังคับให้ผู้ใช้ตรวจและแก้ก่อนกดยืนยันทุกครั้ง ไม่มีการบันทึกเงียบ ๆ
  • กันบันทึกซ้ำ — ระบบจำเลขอ้างอิงของสลิปที่เคยอัปแล้ว ถ้าอัปใบเดิมซ้ำจะเตือนและไม่บันทึกให้
  • ข้อมูลของแต่ละคนแยกขาดจากกัน — ทุกคำสั่งที่ยิงไปหาฐานข้อมูล ถูกกรองด้วยรหัสประจำตัวของคนที่ล็อกอินอยู่เสมอ ไม่มีทางเห็นข้อมูลของคนอื่น แม้แต่แอดมินก็ดูรายการเงินของสมาชิกไม่ได้ ทำได้แค่จัดการบัญชี
  • รหัสผ่านไม่ได้เก็บเป็นตัวหนังสือ — เก็บเป็นค่าที่แปลงแล้วย้อนกลับไม่ได้ ถ้าฐานข้อมูลหลุด รหัสผ่านก็ยังอ่านไม่ออก

  • ครั้งแรกต้องต่อเน็ต — เพื่อโหลดไฟล์ภาษาไทยขนาดประมาณ 10 MB มาเก็บไว้ หลังจากนั้นใช้แบบออฟไลน์ได้

  • ยังไม่มีชุดทดสอบอัตโนมัติ — ตอนนี้ทดสอบด้วยมือทั้งหมด ซึ่งไม่ยั่งยืน
